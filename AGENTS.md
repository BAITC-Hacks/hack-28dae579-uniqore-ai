# AGENTS.md — процесс работы в этом репозитории

Инструкция для любого ИИ-агента и человека, который здесь что-то меняет.
Читается до первой правки.

## Что это

Репетиционный хакатон HackAlem, трек 01 «Агентные системы», кейс 01 «Классификатор
обращений». Скрипт читает обращения из файла и печатает для каждого категорию
(справка / жалоба / другое) и черновик ответа на русском.

Задача считается сделанной, когда закрыт весь Definition of Done ниже, а не когда
код «в целом работает».

## Команды

```bash
python3 main.py                              # основной сценарий, офлайн, без зависимостей
python3 main.py --json                       # тот же результат JSON-массивом
python3 main.py --text "Пропал свет"         # разобрать одно обращение
python3 -m unittest discover -s tests -v     # тесты, сеть не используется
```

Других команд нет: ни сборки, ни установки зависимостей, ни линтера.

## Тиры изменений

Определи тир до начала работы. **Сомневаешься → substantial.**

**Trivial** — опечатка, формулировка, один вес в лексиконе, ≤10 строк в одном файле,
контракт и поведение не меняются. Ветка → commit → PR → merge. Спеку не пишем.

**Substantial** — новая категория, новый режим CLI, смена контракта вывода, новый
источник данных, архитектурная правка. Полный процесс **плюс спека в `docs/`**: что,
зачем, как устроено, какие решения приняты, и обязательная пошаговая проверка
«действие → ожидаемый результат».

Расширяешь задачу — обновляешь существующий документ, а не заводишь второй.

## Git

- Работа только в отдельной ветке: `feature/<суть>` или `fix/<суть>`.
- В `main` — только через Pull Request. Прямой push в `main` запрещён.
- Поток: ветка → commit → push → PR → merge.
- Сообщения коммитов: `feat:` / `fix:` / `docs:` / `test:`, тело — зачем, а не что.
- В конце сообщения коммита: `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

## Definition of Done

Каждый пункт закрывается только после того, как команда реально прогнана.
Список повторяет критерии оценки хакатона — это не формальность, это счёт.

- [ ] **Функциональность (20).** `python3 main.py` проходит путь целиком: вход из файла →
      категория и черновик для каждого обращения → код возврата 0.
- [ ] **Техническая реализация (25).** Логика написана, а не сымитирована. Классификатор
      правильно размечает обращения, которых нет в `messages.txt` — это проверяется
      тестом `test_unseen_messages`.
- [ ] **README (20).** Обновлён, если изменилось поведение, запуск или ограничения.
- [ ] **Воспроизводимость (20).** Проверено в чистом клоне: `git clone` во временную
      папку и `python3 main.py` без `pip install` и без `.env`.
- [ ] **Надёжность (15).** Прогнаны крайние случаи: нет файла (код 2), пустой файл
      (код 0), мусорный текст, недоступный LLM. Трейсбек наружу не выходит.
- [ ] Тесты зелёные.

## Жёсткие правила

Нарушение любого из них — это прямая потеря баллов, а не вопрос вкуса.

1. **Только стандартная библиотека Python 3.** Никаких `pip install`, никакого
   `requirements.txt` с содержимым. Жюри запускает проект в чистом окружении.
2. **Никакого ветвления по тексту тестовых обращений.** Правила лексические и общие.
   Если новая проверка срабатывает ровно на одной строке из `messages.txt` — это
   заглушка, и её место в тестах, а не в классификаторе.
3. **Скрипт обязан работать без ключа и без сети.** LLM — это апгрейд поверх правил,
   а не условие запуска. Любой сбой LLM уводит на правила и пишет об этом в вывод.
4. **Секреты только из переменных окружения.** Ключи не коммитим, не логируем и не
   печатаем — ни целиком, ни частями.
5. **Весь пользовательский текст на русском**: вывод, ошибки, подсказки `--help`.
6. **Ошибки не роняют прогон.** Одно плохое обращение не должно ломать остальные
   четыре; непредвиденное исключение превращается в понятное сообщение и код 1.
7. **Черновик не выдумывает фактов.** Ни адресов, ни кабинетов, ни телефонов, ни
   сроков, которых нет во входных данных. Запрет держится двумя слоями: формулировкой
   в `SYSTEM_PROMPT` и механической проверкой `check_reply`. Ослаблять любой из них
   без замены — нельзя: первая живая проверка показала, что одного промпта мало.
