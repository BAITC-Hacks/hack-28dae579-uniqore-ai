# Классификатор обращений

Трек 01 «Агентные системы», кейс 01. Репетиция HackAlem.

Скрипт читает обращения из `messages.txt` и печатает для каждого категорию
(**справка / жалоба / другое**) и черновик ответа на русском.

## Запуск

```bash
git clone https://github.com/BAITC-Hacks/hack-28dae579-uniqore-ai.git
cd hack-28dae579-uniqore-ai
python3 main.py
```

Python 3.10+, только стандартная библиотека: ни `pip install`, ни ключа, ни сети не
требуется. Флаги: `--input ФАЙЛ`, `--text ТЕКСТ`, `--json`, `--no-llm`.
Вывод всегда в UTF-8, в том числе при перенаправлении в файл или конвейер.

Включить LLM — положить ключ [OpenRouter](https://openrouter.ai/keys) в `.env` проекта:
`cp .env.example .env && chmod 600 .env`, затем строка `LLM_API_KEY=`.

## Что получилось

Категория определяется двумя путями. Есть ключ — один вызов LLM со строгим
JSON-контрактом, ответ валидируется: категория из списка, черновик непустой, на русском
и без выдуманных контактов. Нет ключа, сбой сети или ответ не по контракту —
детерминированные правила: взвешенный лексический скоринг по трём словарям признаков.
Правила штатный режим, а не аварийный, поэтому проект запускается в чистом окружении.

Оба пути на пяти обращениях кейса дают одну разметку:
`справка / жалоба / другое / жалоба / справка`.

Код: `main.py` — ввод-вывод и оркестрация, `triage.py` — классификация, шаблоны ответов
и клиент LLM. Тестов 65, сеть в них не используется.

## Проверка

```bash
python3 main.py                          # 5 блоков: категория и черновик, код возврата 0
python3 -m unittest discover -s tests    # OK, 65 тестов
```

Крайние случаи: нет файла — код 2, пустой файл — код 0, мусорный текст — `другое`,
LLM недоступен — правила с пометкой в выводе. Полная таблица из десяти шагов «действие →
ожидаемый результат» — в [спецификации](docs/spec-triage-classifier.md).

## Ограничения

- LLM-путь прогнан на живом ключе, но качество черновиков на объёме не измерялось:
  пять обращений — не статистика.
- Правила рассчитаны на русский язык; текст целиком на английском попадёт в `другое`.
- Проверка черновика ловит телефоны, ссылки и почту, но выдуманное расположение
  механически не отличить от настоящего — против него работает только запрет в промпте.
- Нет порога «не уверен», нет памяти между запусками, нет батчинга: один вызов LLM на
  обращение.

Подробнее: [спецификация](docs/spec-triage-classifier.md) — архитектура, принятые
решения и полная проверка; [AGENTS.md](AGENTS.md) — процесс разработки.
